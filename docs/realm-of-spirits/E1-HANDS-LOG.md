## Один цикл (чеклист)

1. SoT **Ctrl+S** → **Play** (желательно Stop→Start между тяжёлыми прогонами).
2. Haven → Мика **E** → принять квест.
3. (Опц.) манга / Магазин → Exit в Combat.
4. Мир: **E** лут / ловля (без читов).
5. Бой: **F**, навыки **1** и **2** (≥2 слота).
6. Мика **E** → сдать → видны XP/монеты.
7. (Опц.) Уход / Закалка / Святилище.

**PASS** = дошёл до сдачи без P0 (UI мёртв / бой не кончается / квест сломан / клавиши не работают).  
**FAIL** = P0 или пришлось читом.
