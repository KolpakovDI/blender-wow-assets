## 2. Что осталось до «играбельного MVP / soft launch»

### Core gameplay — ~90% готово

**Есть:** полный цикл Collect→Battle→Quest→Evo→Resonant; BattleOrchestrator; 3 skill slots; element ×1.5/×0.7; soft-respawn; Kami Sanctum product slice.

**Осталось (не блокер demo, но для soft launch):**

- Формальный play-test sprint E1 (n≥10, ≥90% completion, median ≤10 мин) — **процесс, не код**
- Combat feel polish (anim visibility уже был pass; DG clips — blocked)
- Баланс CD/MP по живым метрикам

### Content — ~70% для MVP, ~40% для «полного» продукта

**Есть:** Story 1–7, side 101–116, Hunt 201–218, Resonance 301–305, exploration 8–16 + 107–112 scaffold, 16 линий духов с мешами.

**Не начато / backlog:**

- Side **108–112** scout line (продолжение 107) — кандидат W2, не сделано
- Side **106** «Цикл стихий» polish
- Новые зоны beyond Q2 pads (year plan)
- Live season rotation / новый pool после августа

### Multiplayer / social — ~75% для MVP

**Есть:** P2P trade MVP, fair duel slice, rematch, wayfind, flex/cosmetics Safe-only.

**Не начато:**

- **Guilds** (P2) — stub only
- PvP **slice 3** (rank stub, seasonal cosmetic gate) — B1 backlog
- Rated/ladder PvP, seasons на арене
- Anti-cheat / exploit hardening at scale

### Polish — ~60%

**Есть:** UI packages A–D, ToastRouter, NextStepChip, bag grid, HUD fixes, hub funnel instrumentation.

**Не начато / отложено:**

- Haven décor marathon (FOMO/гача feel polish beyond current)
- Formal hub KR measurement (≥80% brand read — нет n≥10 опроса)
- Audio polish (BGM есть, но 4/4 KR не верифицированы метриками)
- Onboarding для cold-start игроков без dev-знаний

### Infra (DataStore, monetization) — ~65%

**Есть:** Session lock + UpdateAsync; publish; ProcessReceipt idempotency; SeasonLiveOps soft; gacha Robux hook; fair_combat CI.

**Не начато:**

- **ProfileService** migration (Q4)
- Live DataStore round-trip **stress test** (rejoin under load)
- Analytics dashboard для GOALS KR (completion %, agency %, hub funnel)
- Monetization A/B (DevProducts live test beyond Studio)
- Moderation / reporting для P2P trade

### Честно: что NOT started

1. ProfileService live
2. Guilds (beyond fail-closed stub)
3. Online AI mesh generation
4. Haven décor marathon
5. DG proprietary combat clips
6. Allow* expansion unlocks
7. Formal E1 metrics table n≥10
8. Commercial marketing/onboarding pass

## 5. Риски и рекомендации

### Что блокирует launch

1. **Отсутствие формальных метрик E1** — код PASS, но KR1 (≥90% completion) не доказан таблицей
2. **SoT drift** — place vs mirrors рассинхрон без Ctrl+S
3. **DataStore under load** — session lock есть, stress test нет
4. **Combat feel** — без DG clips ощущение боя слабее конкурентов

### Что резать для faster ship

| Cut | Экономия |
|-----|----------|
| E1 formal n≥10 → owner skip + 3 hands | ~1–2 нед |
| B1 PvP slice 3 | ~1 нед |
| Side 108–112 → короткая 2-step side | ~1–2 нед |
| Haven décor | ~2–3 нед |
| ProfileService до post-launch | ~3–4 нед |

**Минимальный ship:** Фаза 1 only → **invite soft launch через 2–4 нед part-time**.

### Рекомендуемый next slice

**Приоритет 1 — Stabilization (не B1 PvP):**

1. Заполнить **E1-HANDS-BUFFER-LOG** (5–10 прогонов) или зафиксировать owner skip в SESSION
2. Один **full regress** Resonant + Sanctum 304/305 + B2 route 115→116
3. Publish smoke: rejoin, spirits persist, quest progress

**Приоритет 2 — если хочется видимого прогресса для игрока:**

- **Content:** side **108–112** (reuse VisitZone/CollectItem, без новых систем) — лучший ROI
- **Не infra:** ProfileService рано; ROI низкий до live player base
- **B1 PvP slice 3** — только если цель «показать социалку другу»; rank stub без combat stats

**Не рекомендую сейчас:** Haven décor, Guilds, AI mesh, Allow* — всё это P2/Q4 по GOALS.
