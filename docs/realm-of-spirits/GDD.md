# Realm of Spirits — GDD v2.0

> Дата: 2026-07-29 (каталог духов / Primary)

## 1. Vision

**High Concept:** MMORPG на Roblox — Хранитель Духов ловит, тренирует и эволюционирует магических существ в мире, где безопасные аниме-хабы соседствуют с боевыми зонами.

**Аудитория:** 9–16 лет, фанаты creature collectors и anime.

**Pillars:** Collect → Battle → Progress → Explore → Socialize

## 2. Core Loop

Исследовать → Найти духа → Бой/Ловля → XP/Монеты → Прокачка → Эволюция → Новый контент → Ранг D→SSS

**Социальный слой:** Safe Zone (хаб) → подготовка/монетизация/трейд → выход в боевую зону → возврат с наградами.

## 3. Gameplay

### 3.1 Ловля
- Нужна ловушка (Id=1), шанс = CatchRate
- Старт: 5 ловушек, 3 зелья

### 3.2 Бой (real-time cooldown)

| Способность | Тип | Значение | MP | CD |
|-------------|-----|----------|----|----|
| Коготь Духа | Attack | 20 dmg | 0 | 2s |
| Призрачный Вихрь | Attack | 35 dmg | 15 | 5s |
| Духовное Исцеление | Heal | 30 HP | 20 | 8s |

Победа: +50 XP, +30 монет. Поражение: respawn 1.5s.

**Стихии (Primary):** Fire → Earth → Wind → Water → Fire · множители ×1.5 / ×0.7

**Aspect** — вкус линии внутри Primary (Ash, Magma, Mist…) для UI/скиллов, не для матчапа.

**Правило 4×4 (locked 1B / 2B):**
- На Primary — **4 линии**, у каждой база + эво → **8 форм / стихия**, **16 линий / 32 канон-формы**.
- В бою у духа только **3 уникальных** скилла линии (база открывает 2, эво — все 3).
- У Primary — **2 ElementPassives** (пассив/мета: tip, soft-бафф); **не** слоты action bar.

## 4. Локация сценария: Safe Zone — «Otaku Haven»

**Тип зоны:** безопасная (Safe Zone), без PvE/PvP-угроз. Социальный хаб, квесты, монетизация и подготовка к выходу в боевую зону.

**Концепт:** двухэтажный современный аниме-магазин с неоновой вывеской. Игроки демонстрируют статус через кастомные машины у входа, коллекционный мерч и редкие аксессуары.

### Сцена 1: Вход в магазин и социальный хаб

**Визуальный ряд:**
- Игрок подходит к двухэтажному коттеджу с неоновой вывеской **«Otaku Haven»**
- Перед входом — кастомные спорткары других игроков (демонстрация социального статуса)
- У дверей — картонная фигура (standee) главного героя игры
- Звук: расслабляющий Lo-Fi опенинг

**Геймплей и интерактив:**
1. Игрок переступает порог → звук колокольчика
2. Зона **Генкан**: персонаж автоматически разувается (обувь → домашние тапочки)
3. LED-витрины с фигурками (PointLight + мерцание)
4. Тканевые плакаты на стенах слегка колышутся от шагов игрока

**Цели дизайна:** первое впечатление «уютного аниме-магазина», сигнал безопасности, намёк на социальность.

---

### Сцена 2: Взаимодействие с аниме-квестором (Мика)

**Визуальный ряд:**
- За кассовым прилавком, обклеенным стикерами, стоит **Мика** — классический квестор (девушка в стилизованной форме гильдии с кошачьими ушками)
- Над головой — большой глянцевый жёлтый восклицательный знак (квест доступен)

**Сценарный диалог и механика:**

| Шаг | Действие | Результат |
|-----|----------|-----------|
| 1 | Игрок активирует ProximityPrompt у Мики | Камера плавно приближается (Focus Mode), 2D-Live анимация |
| 2 | Мика кланяется | Анимация приветствия |
| 3 | Реплика (радость) | «Добро пожаловать в Otaku Haven! О боже, ты выглядишь как настоящий герой! Мне как раз нужна помощь...» |
| 4 | Иконка пота над головой | Анимация паники |
| 5 | Реплика (паника) | «Хулиганы из банды "Shadow" разгромили наш склад в Сеуле и украли партию редкой манги! Если ты вернёшь её, я щедро тебя награжу!» |
| 6 | GUI квеста | Кнопки: **[ Принять ]** (500 монет + 1 Секретный Билет) / **[ Отказаться ]** |
| 7 | Принятие квеста | Мика указывает на выход |

**Связь с текущей реализацией:** QuestMaster (Алиса) — прототип Мики; система квестов через `QuestSystem`, UI через `QuestUI`, индикатор «?» при готовности к сдаче.

---

### Сцена 3: Зона монетизации и прокачки (внутри магазина)

Игрок готовится к квесту, не выходя из Safe Zone.

#### Секция 1: Стеллажи с мангой (прокачка / лор)
- **Действие:** подойти к полке → **[ E ]** — «Читать томик "Путь Меча"»
- **Эффект:** анимация перелистывания страниц
- **Награда:** временный бафф **+15% к урону на 30 минут** (помогает в квесте Мики)

#### Секция 2: Витрина «Гашапон» (гача-монетизация)
- **Действие:** яркий автомат со светящимися капсулами
- **Стоимость:** внутриигровые монеты или Robux (мгновенное получение)
- **Эффект:** анимация падения капсулы; возможный дроп — мифическая мини-фигурка (например, Тоторо)
- **FOMO:** таймер на автомате — «До конца лимитированной коллекции осталось 2 часа!»

#### Секция 3: Примерочная и трейд-зона (социализация)
- **Действие:** надеть выбитую фигурку на рюкзак как аксессуар
- **Социал:** другой игрок кидает **Trade Request**, предлагая обмен (редкая фигурка ↔ уникальный меч)

**Связь с текущей реализацией:** `TradeSystem`, магазин в `UIController`; гача и примерочная — **Planned** (Roadmap Beta/Release).

---

### Сцена 4: Выход на квест

1. Игрок получил бафф от манги, экипировал мерч, взял квест у Мики
2. При приближении к выходу:
   - Музыка: Lo-Fi → динамичный боевой J-Rock
   - Надпись на экране: **«Выход в боевую зону: Район Акихабара»**
3. Переход из Safe Zone в открытый мир с духами, боями и квестовыми целями

### Реализация сценария в Roblox Studio

| Элемент | Технология | Примечание |
|---------|------------|------------|
| Диалог Мики | `ProximityPrompt` + `TweenService` | Плавное открытие GUI диалогов |
| Focus Mode | Camera tween к NPC | CFrame lerp / CameraSubject |
| 2D-Live / эмоции | BillboardGui / SpriteSheet / UI анимации | Радость, паника, указание |
| LED-витрины | `PointLight` + скрипт мерцания | Random brightness / sine wave |
| Звук колокольчика | `Sound` в зоне входа (Region3/Touched) | Trigger один раз при входе |
| Разувание (Genkan) | Смена Accessory / атрибут «Indoor» | Character outfit swap |
| Бафф от манги | Временный модификатор урона | Player attribute + timer 30 мин; интеграция с `SpiritDatabase.CalculateDamage` |
| Гашапон | `RemoteEvent` + RNG таблица дропа | Монеты / Robux через MarketplaceService |
| FOMO-тimer | `os.time()` + UI countdown | Синхронизация с сервером |
| Трейд | `TradeSystem` (существует) | Trade Request UI |
| Смена музыки | `SoundService` / зоны с Region3 | Crossfade Lo-Fi ↔ J-Rock |
| Safe Zone | Zone без спавна врагов | Флаг `IsSafeZone` на регион |

**Приоритет внедрения:**
1. **Alpha+:** Safe Zone геометрия, Мика/QuestMaster, квестовый flow (есть)
2. **Beta:** манга-бафф, гача, LED-витрины, музыкальные зоны
3. **Release:** полный сценарий (4 сцены), трейд-хаб, машины игроков, 2D-Live диалоги, FOMO-сезоны

## 5. World

### 5.1 Safe Zone
- **Otaku Haven** — главный социальный хаб (см. раздел 4)
- Генkan, касса Мики, стеллажи манги, гашапон, примерочная, выход в Akihabara

### 5.2 Боевые зоны
- **Район Акихабара** — основная PvE-зона (открытый мир)
- PlayerHouse (0,0,0) — база (legacy / личное жилище)
- BattleArena (100,0,0) — арена
- Open world / habitats — спавн духов по `ZoneConfig` (Hunt #1–17), respawn 30–120s
- Шаблоны: `ReplicatedStorage.RealmOfSpirits.SpiritTemplate*` — см. каталог §3.2.1
- QuestMaster / Мика — `ZoneConfig.QuestMasterPosition`

## 6. UI (UIController)
HUD, Spirit Menu, Battle UI, Quest UI, Inventory, Evolution UI, Shop UI — code-generated.

Для Otaku Haven (planned): диалоговое окно квеста, GUI гашапона, таймер FOMO, Trade Request popup.

## 7. Data
DataStore: RealmOfSpirits_v2, autosave 300s.

Поля: Level, XP, Coins (3 типа), Crystals, Reputation, Spirits[], Inventory[], Quests, Stats, Buffs[], Cosmetics[].
