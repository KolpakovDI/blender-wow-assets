# Иерархия и нумерация духов (канон 4×4)

SoT: `SpiritDatabase.Hierarchy` / `Code` / `GetCode()` / `MigrateId()`.

## Схема

| Primary | № | Код линий |
|---------|---|-----------|
| Огонь (Fire) | **1** | 1.1 … 1.4 |
| Земля (Earth) | **2** | 2.1 … 2.4 |
| Ветер (Wind) | **3** | 3.1 … 3.4 |
| Вода (Water) | **4** | 4.1 … 4.4 |

- **База** Code = `P.L` · Id = `P*10+L` (11, 12, … 44)
- **Эво** Code = `P.Le` · Id = база + 1000 (1011, 1012, …)
- **Core** = `.1` (Aspect = Primary)
- Кристаллы эволюции (ItemCatalog) **без смены**: 101–118
- Старые Id 1–18 / 101–118 → `LegacyToId` / `MigrateId` при загрузке сейва

```
1 Огонь
├─ 1.1 ★ Огненный Кот → 1.1e Тигр          (11 / 1011)
├─ 1.2   Пепельный Саламандр → Инферно-Дракон (12 / 1012)
├─ 1.3   Световой Единорог → Альфа           (13 / 1013)
└─ 1.4   Лавовый Краб → Вулканический Титан  (14 / 1014)

2 Земля
├─ 2.1 ★ Каменный Голем → Горный Титан
├─ 2.2   Моховой Олень → Древний Энт
├─ 2.3   Стальной Жук → Железный Колосс
└─ 2.4   Ядовитая Гадюка → Василиск-Гидра
   (архив 2.5 Песок, 2.6 Кристалл)

3 Ветер
├─ 3.1 ★ Ветряной Лис → Буревой Кицунэ
├─ 3.2   Грозовой Дракон → Левиафан
├─ 3.3   Теневой Пёс → Волк
└─ 3.4   Небесный Сокол → Феникс

4 Вода
├─ 4.1 ★ Водный Карп → Цунами-Карп
├─ 4.2   Ледяная Птица → Феникс
├─ 4.3   Лунный Кролик → Цукуёми-Страж
└─ 4.4   Туманный Дух → Призрачный Кирин
```

Итого канон: **16 линий / 32 формы**.
