# Умения духов — справочник

> **SoT (код):** `ReplicatedStorage.RealmOfSpirits.SkillCatalog` · `SpiritDatabase`  
> **Зеркала:** [`studio/SkillCatalog.lua`](studio/SkillCatalog.lua) · [`studio/SpiritDatabase.lua`](studio/SpiritDatabase.lua)  
> **Канон:** 16 линий × 3 навыка = **48** action-skills · см. [`GDD.md`](GDD.md) §3.2 · [`SPIRIT-HIERARCHY.md`](SPIRIT-HIERARCHY.md)

## Правила боя

- В бою у **Хранителя** на панели (клавиши **1 / 2 / 3**) — навыки **активного духа** (`SkillIds`).
- **База:** 2 слота · **эво:** 3 слота; signature-«шторм» линии — **слот 1** (Identity).
- **ElementPassives** (2 на Primary) — не кнопки, тихий бонус ATK/DEF.
- **Resonant (Ками):** 3 слота из смеси линейных навыков доноров + возможный unique (300–307).

### Дальность и тип урона

Два независимых признака: **где бьёт** и **чем бьёт**.

| | **Физический** (оружие / снаряд) | **Заклинание** (магия духа) |
|--|----------------------------------|-----------------------------|
| **Ближний** | меч, когти, кулак, клешни, пике | молниеносный удар вплотную, касание тумана |
| **Дальний** | **лук, арбалет, ружьё**, стрела, болт, метательное | луч/шторм стихии, волна, исцеление |

| Поле в коде | Значения | Смысл |
|-------------|----------|--------|
| `Range` | `Melee` · `Ranged` | Дистанция применения |
| `DamageKind` | `Physical` · `Spell` | **Physical** = урон оружием или физическим снарядом (и в melee, и на distance); **Spell** = стихийная магия без «пули/стрелы» |

Примеры **дальний + физический:** «Ледяная стрела» (лук/арбалет); в будущем — выстрел из ружья, арбалетный болт.  
Примеры **дальний + заклинание:** «Пламенный всплеск», «Цунами», «Световой луч» (магический луч, не пулемёт).

SoT: `SkillCatalog.CombatMeta` → попадает в `GetClone` как `Range` / `DamageKind`.
